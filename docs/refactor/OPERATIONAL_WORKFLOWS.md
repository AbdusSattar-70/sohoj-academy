# দৈনন্দিন পরিচালনা

## প্রথমবার
নিজের bootstrap admin → academy/campus/division confirmation → seeded directory review → চলমান programme → fees/discount → batch → ready।
আগের setup ধাপ edit করা যাবে। শুধুমাত্র কাজের prerequisite না থাকলে সেই কাজ blocked এবং inline correction link; অপ্রাসঙ্গিক setup দিয়ে পুরো app lock নয়। Teacher/referrer account-কে admin setup করাতে হবে না।

## Public CRM
বর্তমান design অপরিবর্তিত। Active published programme থেকে catalogue। Interest/admission without account। ভুল class/subject/programme combination preference হিসেবে গ্রহণ; valid contact/required identity/consent/size validation থাকবে।
Inactive/stale catalogue preference submitted snapshot-এ রাখা যেতে পারে, verified placement নয়। Public new school text unverified suggestion; master school auto-create নয়। Application reference এবং black/white acknowledgement। এটি admission confirmation বা payment receipt নয়।
Admin enquiry খুলে original preference দেখে actual identity/placement যাচাই করেন; তারপর একই admission desk। Walk-in direct admission fabricated Prospect তৈরি করে না।

## এক-page admission desk
| ধাপ | কাজ | ফল |
| --- | --- | --- |
| Identity | existing person search/new student+guardian; adult/minor template | reusable verified identity, draft |
| Placement | division, current programme, batch; inline missing master | eligible actual placement |
| Terms | fees, discount reason, extras, Organic/referrer select/create | authoritative payable preview |
| Paper consent | guardian/student applicable signature date/file reference | physical evidence for current identity revision |
| Review | সমস্ত প্রয়োজনীয় তথ্য/fees একটি summary; edit section link | required checks complete |
| Confirm | atomic acceptance + permanent ID/roll + initial invoice; eligible enrollment | unpaid amount remains due |
| Collection/Print | no payment / partial / full actual payment; receipt/acknowledgement | same page complete |

Page-level sections; current/completed steps clickable, future invalid actions locked with explanation। Save draft anytime eligible, resume register। Identity corrected before confirm renews applicable paper consent; financial history rewrite নয়।
Confirmation ও initial invoice atomic; enrollment একই transaction-এ policy satisfied হলে, অন্যথায় clear “awaiting payment/placement” state। Collection পৃথক retry-safe command: money entry failed/uncertain হলেও confirmed admission intact। User stays same page; outcome recovery checks request result, never blind duplicate payment।
Receipt কেবল actual collection। Printable options: blank application, reviewed application/consent, acknowledgement, invoice/due, actual receipt।
Payment policy simple: allow due / minimum payment / full payment; admin direct actions, no second approval। Payment section allows permitted discount/scholarship via audited adjustment before recomputed collection amount।

## People ও staff
এক person profile-এ applicable student/guardian/staff/referrer relationships। নিজ নিজ module canonical editor; shortcut duplicate implementation নয়।
Staff request → identity match/verify → responsibility/access → secure setup → account activated। Requested role never auto-grants। Teacher works assigned classes; admin takes staff attendance/verified work hours and configures fixed/hourly/teaching-share terms। One remuneration statement distinguishes teaching and acquisition bases, preventing same earning twice।

## Academic workflows
School: year/class/section/roll, attendance, assessment, progress and explicit year promotion।
Coaching: session/subjects/batch, routine, attendance, homework/tests/progress।
Training: course duration/cohort, adult contact, sessions, assessment/completion।
Teacher draft → submit → admin approve or return with note। Corrections keep approved history; admin direct operational setup does not enter generic review queues।
Question bank authoring/search + paper selection/export scoped implementation, not unsupported AI-generation claim।

## Simple finance
Invoice fee earned/charged under actual delivery/billing policy; future-course advance is not automatically today's earned income। Student due = net invoice less net allocated money। Discounts and scholarships named separately, not unexplained “student credits”।
Running expense incurred amount/date/category; paid/unpaid/partial settlement। Salary/referral accrued remuneration counted once as expense; payment reduces payable, not another expense।
Referral reward on actual net collected tuition after tuition discount/refund; configurable rate/basis/window, snapshot entitlement and corrections। Not admission/exam/material fee unless explicit future policy। Already paid reward reduced after refund creates recoverable/offset balance, no silent erase।
Division operating profit = recognized net fee income − recognized running expenses − staff/referral remuneration। Cash movement = actual receipts − actual payouts। Shared cost allocated once, residual visible; shared cash not equal shared revenue।
Example: net earned fee 50,000, collected 40,000, expenses/remuneration 30,000, paid 25,000 → operating profit 20,000, cash surplus 15,000, student due 10,000, expense payable 5,000。
No depreciation/assets module; equipment outlay separately labelled cash expenditure excluded from running operating profit। Owner money/manual opening cash separate non-income entry only if necessary to reconcile cash; no capital-management engine।
No statutory/full-balance-sheet accounting claim। Same summaries use database aggregates, not downloaded-row sums।

## Workspaces
Admin Today shows action links/counts। Teacher My day shows classes, attendance/tasks, review feedback, hours, remuneration paid/due, referral summary। Referrer sees only own permitted referral financial statement। Each workspace scoped; data from another user's unrelated records never exposed।
